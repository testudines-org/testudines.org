# Testudines.org

Testudines.org is a non-profit project dedicated to turtles and tortoises.

## Project

Testudines.org is being developed using:

- .NET 10
- C#
- Blazor
- MariaDB
- Git
- Linux / Ubuntu Server

## Repository structure

- `src` - Application and libraries
- `tests` - Automated tests
- `docs` - Project documentation
- `scripts` - Development and deployment scripts
